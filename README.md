# Game Box 游戏盒子

运行在 aarch64 嵌入式 Linux 开发板上的 LVGL 图形应用，集成 2048、数字华容道、记忆翻牌、打地鼠四个小游戏。登录界面、水平滚动的游戏选择界面和一套可复用的 UI 组件层都基于 LVGL 9 构建，显示与触摸直接对接 Linux 帧缓冲和 evdev 设备。

## 功能

- 登录界面（虚拟键盘、账号/密码输入框）
- 水平滚动的游戏选择界面，触摸抬手切换游戏
- 2048：四方向滑动合并、图片图块渲染、随机生成新数字
- 数字华容道：4x4 滑块拼图，步数统计、复原判定、重开
- 记忆翻牌：8 对汉字配对，翻开不匹配时延时自动翻回
- 打地鼠：3x3 地洞、30 秒回合、得分与失误统计

## 构建与运行

交叉编译工具链已在 CMakeLists.txt 中配置好：

```bash
mkdir build && cd build
cmake ..
make        # 可执行文件输出到 bin/main，LVGL 动态库输出到 bin/liblvgl.so
```

在开发板上部署运行：把 `bin/main`、`bin/liblvgl.so` 与 `tu/` 资源目录放到同一目录，在该目录下执行（需要帧缓冲与触摸设备权限）：

```bash
./main
```

## 设计说明

**显示与输入**：main.c 通过 lv_linux_fbdev_create 创建帧缓冲显示设备并绑定 /dev/fb0，通过 lv_evdev_create 创建指针类输入设备绑定触摸节点，主循环以 5ms 周期调用 lv_timer_handler。随机数种子由系统时间初始化，供 2048 使用。

**构建与部署**：CMake 配置 aarch64 交叉工具链，把 LVGL 编译为动态库（禁用 examples/demos，保留内部依赖的 thorvg），库产物统一输出到 bin 目录。可执行文件设置 `$ORIGIN` rpath，在板端同级目录自动找到 liblvgl.so，部署时不需要配置 LD_LIBRARY_PATH。lv_conf.h 由 configure_file 从 my_src 复制到 LVGL 目录后参与编译。图片与字体以相对路径 `tu/` 引用（`A:` 为 LVGL 文件系统盘符，经 POSIX 后端按进程工作目录解析），资源随仓库提供，部署时与可执行文件放同一目录即可。

**源文件清单**：my_src/CMakeLists.txt 使用显式源文件列表而非 file(GLOB)。GLOB 在新增 .c 文件时不会可靠刷新目标列表，Makefile 生成器下只打印 mismatch 警告、本次仍按旧列表编译，链接阶段报 undefined reference；显式清单行为可预期，新增模块补一行即可。

**UI 组件层**：0ui.c 维护一个按钮样式池，按背景色、文字色、字号查找或复用样式，避免重复创建 lv_style。中文字体按字号懒加载并缓存，同字号只加载一次 TTF，避免逐控件加载耗尽板端内存。屏幕、标签、输入框、开关、滑条、进度条、图片按钮、确认弹窗、时钟等控件统一封装，各游戏只调用接口。

**屏幕切换**：游戏选择界面的按钮回调区分按下与抬手事件——按下只做缩放与透明度视觉反馈，抬手才执行 lv_screen_load，长按不会误触发。每个游戏是独立屏幕对象，由 layout.c 的 user_data 编号分发。

**2048**：4x4 棋盘用带合并标记的结构体数组表示，四个方向各自做移动与相邻合并，标记位保证同一回合内一个格子不参与两次合并；棋盘数字映射到 BMP 图块显示，新数字按 90% / 10% 概率生成 2 / 4。

**数字华容道**：开局从已复原状态出发，随机走 300 步合法移动生成。数字华容道的随机排列中有一半在数学上无解（逆序数奇偶性），用合法步倒推可保证生成的局面一定可复原。

**记忆翻牌**：翻开第二张且不匹配时设置 lock 标志屏蔽后续点击，并创建 600ms 一次性定时器，回调中把两张牌翻回并解除 lock。全部 8 对配齐后弹出重开确认框。

**打地鼠**：两个常驻定时器分别负责 750ms 随机换洞与 1 秒回合倒计时，由 running 标志门控——不销毁、不重建定时器，避免指针悬空。进入界面时由 mole_enter 重置开局，返回游戏盒子时先停局再切屏，回合不会在后台空跑。

## 已知限制

- 图片与字体依赖运行目录下的 `tu/`，程序必须从资源同级目录启动（工作目录即基准）
- 触摸设备节点固定为 `/dev/input/event6`，不同板子的 event 编号需要相应调整
- 布局按 1024x600 屏幕坐标编写，未做按分辨率自适应
- 打地鼠的两个定时器随应用常驻，靠 running 标志空转，会有极小的固定开销

## 目录结构

```
.
├── CMakeLists.txt          顶层构建：交叉工具链、LVGL 动态库、输出目录与 rpath
├── my_src/
│   ├── CMakeLists.txt      应用源文件显式清单
│   ├── main.c              入口：LVGL / 显示 / 输入初始化与主循环
│   ├── layout.c/.h         登录界面、游戏选择界面、屏幕切换
│   ├── 0ui.c/.h            UI 组件层（样式池、字体缓存、通用控件）
│   ├── 2048.c/.h           2048 游戏
│   ├── game15.c/.h         数字华容道
│   ├── flipcard.c/.h       记忆翻牌
│   ├── mole.c/.h           打地鼠
│   ├── mouse_cursor_icon.c 鼠标指针图标
│   └── lv_conf.h           LVGL 配置（构建时复制到 lvgl/）
├── tu/                     图片与字体资源（2048 数字图块、界面背景、hei.TTF 中文字体）
└── lvgl/                   LVGL 9 上游源码（引入的第三方库，非本项目代码）
```

`lvgl/` 为项目直接引入的 LVGL 9 官方源码树，包含其自带的 demos、tests 与文档资源；本项目的代码全部位于 `my_src/` 与顶层 `CMakeLists.txt`。
